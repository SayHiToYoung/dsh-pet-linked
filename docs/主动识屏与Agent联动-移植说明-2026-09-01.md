# 主动识屏 + Agent 联动 —— 上游能力移植说明（2026-09-01）

本文档记录把上游 [MerZlin/dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop) 的两个能力
（`pet/proactive.py` 主动识屏、`pet/agent_link.py` 多 Agent 联动）移植进本分支的改动清单、
架构接线、配置模型与验证结果，供后续维护与排查参考。

> 背景：上游在 8/27 起陆续新增了这两个模块；本分支此前 fork 时未包含，属能力补齐而非重复造轮子。
> 移植目标：**按现有新版 UI/架构组织，不破坏既有情境感知 / 主动关怀 / 看看屏幕 / 办公区联动**。

## 3. 配置模型

### `proactive_screen`（主动识屏，默认全关）
```jsonc
{
  "enabled": false, "dry_run": false, "preset": "balanced",
  "allow_when_mouse_through": true, "whitelist": [],
  "dwell_seconds": 45, "require_idle": false, "min_idle_seconds": 30,
  "cooldown_minutes": 5, "daily_cap": 15,
  "min_request_interval_seconds": 60, "change_threshold": 8,
  "prefer_free_provider": true, "pre_cue": true
}
```
- 预设档位：quiet（90s/10min/8 次）、balanced（45s/5min/15 次）、active（20s/3min/25 次）
- 白名单规则：`进程名`（如 `msedge.exe`）= 关注该软件；`title:关键词` = 只看标题含词的窗口；留空 = 不识屏

### `agent_link`（多 Agent 联动，默认全关）
```jsonc
{
  "dsh": false, "claude": false, "cursor": false, "opencode": false,
  "custom_agents": [],
  "notify_state": false, "notify_done": true, "notify_activity": false,
  "sound_enabled": false,
  "sound_start_path": "builtin:agent-start",
  "sound_done_path": "builtin:agent-done",
  "sound_error_path": "builtin:agent-error",
  "sound_volume": 0.65, "sound_cooldown_seconds": 2.0,
  "sound_start_enabled": true, "sound_done_enabled": true, "sound_error_enabled": true
}
```
- `custom_agents`：`[{key, name, path}]`，key 须匹配 `^[a-z0-9][a-z0-9_-]{0,31}$` 且不与内置键冲突，上限 8 条；只读监听指定 JSONL 事件文件，无需授权
- 事件协议：`<config.dir>/agent-events/<agent>.jsonl`，字段 `{event|state, tool?}`；六态词汇 `idle / thinking / working / attention / sleeping / error`

## 4. 平台与授权

- **主动识屏仅 Windows**（`sys.platform == "win32"` 守卫）：macOS/Linux 上设置页与右键菜单自动隐藏，即使手改 config 也不起定时器
- **DSH / Claude 首次开启弹授权窗**：DSH 走 `node <pnpm> add` 安装桥接插件到所有真实 profile（绕过 dsh CLI 的 Windows 空格路径缺陷）；Claude 向 `~/.claude/settings.json` 注入事件 hooks（数组对象格式，只动带 `x-dsh-pet` 标记的条目）。关闭联动自动卸载；其他多开实例仍在使用时保留
- **Cursor / OpenCode 零安装**：只读 `~/.cursor/projects/**/agent-transcripts/*.jsonl` 与 `~/.local/share/opencode/opencode.db`
- **隐私红线**：主动识屏截图只在内存处理不落盘（右键「看看屏幕」才落盘存档）；陪伴记忆只存进程名 + 活动分类，不存窗口标题；事件只存元数据
